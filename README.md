# નવો વ્યાપાર (Navo Vyapar) - ગુજરાતી ઇન્ડિયન બિઝનેસ બોર્ડ ગેમ 🎲🏛️

આ ગેમ તમે આપેલા અસલ **વોરા "નવો વ્યાપાર" (અમદાવાદ/ઇન્ડિયા બિઝનેસ)** બોર્ડના આધારે HTML, CSS અને JavaScript માં બનાવવામાં આવી છે.

---

## 🌟 નવીનતમ અપડેટ્સ (New Features & Mobile Accessibility)

### ૧. મોબાઇલ-ફર્સ્ટ અને વડીલો માટે ખાસ સુવિધા (Senior Accessible & Mobile-First):
- **એક્ટિવ ટાઇલ ફોકસ કાર્ડ (Active Tile Focus Card):**
  - મોબાઇલની નાની સ્ક્રીન કે આંખની તકલીફવાળા વૃદ્ધ લોકો માટે, કોઈપણ ખાના પર જતાં જ સૌથી ઉપર મોટા અક્ષરોમાં શહેરનું નામ, માલિકનું નામ અને ભાડું/કિંમત સ્પષ્ટ દર્શાવાય છે. નાના અક્ષરો વાંચવા માટે આંખો ખેંચવાની જરૂર નથી!
- **👓 મોટા અક્ષરો બટન (Senior Mode):**
  - હેડરમાં આપેલ બટન દબાવવાથી તમામ અક્ષરો અને બટનો મોટા થઈ જાય છે.
- **મોબાઇલ બોટમ એક્શન બાર (Thumb Zone):**
  - મોબાઇલ પર નીચે જ મોટા મોટા ટચ બટન આપેલા છે (પાસા ફેંકો, લોન, મિલ્કતો, દાવ પૂરો).

### ૨. ૧ માણસ + ૫ હોંશિયાર AI બોટ્સ (કુલ ૬ ખેલાડીઓ):
- તમે એકલા **૧ માણસ તરીકે ૫ સ્માર્ટ કોમ્પ્યુટર બોટ્સ** સામે રમી શકો છો:
  1. **તમે (લાલ)**
  2. **બોટ ૧: રમેશ (લીલો)**
  3. **બોટ ૨: સુરેશ (પીળો)**
  4. **બોટ ૩: મહેશ (વાદળી)**
  5. **બોટ ૪: પરેશ (જાંબલી)**
  6. **બોટ ૫: કલ્પેશ (કેસરી)**

### ૩. વાસ્તવિક માણસ જેવો સ્માર્ટ AI બોટ (Human-Like Pro Intelligence):
- કોમ્પ્યુટર હવે સાવ સરળ કે મૂર્ખ નથી, તે સાચા માણસની જેમ રમે છે:
  - **વ્યૂહાત્મક ખરીદી:** જો કોઈ મિલ્કતથી પોતાનો કલર સેટ પૂર્ણ થતો હોય કે સામેવાળા માણસની મોનોપોલી રોકાતી હોય, તો બોટ તે મિલ્કત અવશ્ય ખરીદશે.
  - **બેંક લોન લેવાની ચતુરાઈ:** જો બોટ પાસે રોકડ ખૂટતી હોય અને મહત્વનું શહેર ખરીદવું હોય, તો બોટ જાતે બેંક પાસે જઈને લોન લઈને પણ શહેર ખરીદશે!
  - **બાંધકામ (Houses & Hotels):** આખો સેટ બનતાં જ બોટ વધારાના પૈસાથી ઘરો અને હોટેલ બાંધશે.
  - **દેવું ચૂકવણી:** દેવું થતાં બિનજરૂરી મિલ્કતો ગીરો મૂકશે અને પૈસા આવતાં લોન ભરપાઈ કરી મિલ્કતો છોડાવી લેશે.
